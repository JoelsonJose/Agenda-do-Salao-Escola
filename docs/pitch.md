# Roteiro de pitch (rascunho)

**Duração: 90 segundos**, conforme a atividade. Ensaiar com a demonstração antes de gravar.

> Nosso projeto é a Agenda do Salão-Escola, do Desafio 03. Ele resolve um problema comum na recepção: marcar duas clientes com a mesma profissional no mesmo horário.
>
> A aplicação mostra a agenda do dia, permite escolher serviço, profissional e horário, calcula automaticamente a duração e recusa conflitos com uma mensagem clara. Também permite cancelar sem apagar o histórico. A agenda respeita o expediente de segunda a sábado, das oito da manhã às oito da noite, no horário de Brasília.
>
> A interface React conversa com uma API Java e Spring Boot hospedada no Azure App Service. Na nuvem, os dados ficam no Azure SQL; localmente, usamos H2 em arquivo. As credenciais de conexão ficam nas configurações do App Service. Os testes cobrem criação, conflito, cancelamento, horário de funcionamento e consulta da agenda.
>
> Escolhemos o nível A, com App Service e Azure SQL gerenciado. Os cenários de aceite passaram e a reserva de teste permaneceu no banco depois do reinício. Vamos mostrar a agenda de 30 de novembro, um conflito recusado, o código real do grupo com a palavra do dia e, durante o teste do professor, o registro `PROF-HHMM`.

**Antes de gravar:** anexar as quatro capturas da prova de persistência com data e hora visíveis, incluir o link real do vídeo nas evidências e usar o código do dia informado pelo professor no registro de persistência. Este roteiro não é uma gravação.
